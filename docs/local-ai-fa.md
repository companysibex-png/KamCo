# راهنمای هوش مصنوعی لوکال برای KamCo

این سند توضیح می‌دهد چطور روی **سیستم خودتان** یک هوش مصنوعی رایگان را به دیتابیس و کد KamCo وصل کنید تا گزارش فروش را تحلیل کند، تست‌ها را اجرا کند و کد را بررسی کند.

## چه چیزهایی اضافه شد؟

| فایل / بخش | کار |
|---|---|
| `scripts/sales-report.py` | مستقیم از `kamco.db` گزارش فروش می‌سازد (بدون نیاز به اجرای سرور) — خروجی JSON یا CSV |
| Seed داده فروش | اگر جدول سفارش‌ها خالی باشد، ~۱۱۲ سفارش واقع‌گرایانه در ۴ ماه اخیر ساخته می‌شود |
| `KamCo.Api.Tests` | ۳۲ تست Integration با xUnit — با `dotnet test` اجرا می‌شوند |

## ۱. اجرای گزارش فروش

پیش‌نیاز: فقط Python 3.8+ (کتابخانه استاندارد، هیچ نصب اضافه‌ای لازم نیست).

```bash
cd KamCo
python scripts/sales-report.py                 # خروجی JSON در ترمینال
python scripts/sales-report.py --format csv    # فایل‌های CSV در پوشه reports/
python scripts/sales-report.py --format both --outdir reports
python scripts/sales-report.py --months 3      # فقط ۳ ماه آخر
```

مسیر دیتابیس به‌طور خودکار پیدا می‌شود (`KamCo.Api/kamco.db`)؛ اگر جای دیگری است با `--db path\to\kamco.db` بدهید.

**گزارش شامل:** درآمد کل، میانگین ارزش سفارش، نرخ لغو، روند ۳۰ روز اخیر نسبت به ماه قبل، فروش ماهانه، پرفروش‌ترین محصولات و دسته‌ها، هشدار کمبود موجودی.

## ۲. وصل کردن هوش مصنوعی رایگان به سیستم خودتان

پیشنهاد: **Gemini CLI** (رایگان با اکانت گوگل، حدود ۱۰۰۰ درخواست در روز). اگر دسترسی به گوگل ندارید: **Qwen Code** (۲۰۰۰ درخواست رایگان در روز).

```bash
# نصب (Node 18+ لازم است — برای فرانت همین را دارید)
npm install -g @google/gemini-cli     # یا: npm install -g @qwen-code/qwen-code

# داخل پوشه پروژه
cd KamCo
gemini        # بار اول لاگین با اکانت گوگل
```

حالا داخل خود ایجنت این نمونه درخواست‌ها را می‌توانید بنویسید:

```text
اسکریپت scripts/sales-report.py را اجرا کن، خروجی JSON را تحلیل کن و
سه نکته مهم برای مدیریت فروشگاه به فارسی بگو.
```

```text
با اجرای dotnet test وضعیت تست‌ها را بررسی کن؛ اگر تستی fail شد علتش را توضیح بده.
```

```text
به فایل KamCo.Api/kamco.db کوئری بزن: ۵ محصولی که بیشترین درآمد را داشته‌اند
با نمودار متنی نشان بده.
```

ایجنت خودش دستورات را اجرا می‌کند، خروجی را می‌خواند و تحلیل می‌نویسد — بدون اینکه چیزی از سیستم شما به من (دستیار ابری) ارسال شود، مگر خودتان بفرستید.

> **نکته حریم خصوصی:** ایجنت‌های ابری (Gemini/Qwen) متن درخواست و خروجی دستورات را برای پردازش به سرور مدل ارسال می‌کنند. اگر ۱۰۰٪ آفلاین می‌خواهید: [Ollama](https://ollama.com) + مدل `qwen2.5-coder` (نیازمند ~۸ گیگ رم).

## ۳. اجرای تست‌ها

```bash
cd KamCo
dotnet test
```

۳۲ تست روی دیتابیس SQLite درون‌حافظه‌ای اجرا می‌شوند — هیچ فایلی تغییر نمی‌کند و به شبکه نیاز نیست. پوشش: ثبت‌نام/لاگین، نقش‌ها (Admin/User)، CRUD محصولات و دسته‌ها، چرخه سفارش، رزرو موجودی، و سلامت داده‌های دموی فروش.

## ۴. نکات

- **حذف داده دمو:** اگر نمی‌خواهید سفارش‌های نمونه ساخته شوند، متغیر محیطی `KAMCO_NO_DEMO_ORDERS=1` را قبل از اجرا تنظیم کنید.
- **بازسازی کامل دیتابیس:** سرور را ببندید، فایل `KamCo.Api/kamco.db` را پاک کنید و دوباره اجرا کنید — همه‌چیز دوباره seed می‌شود.
- **گزارش برای AI:** خروجی JSON کلیدهای انگلیسی دارد تا ابزارها پایدار بخوانند؛ از ایجنت بخواهید تحلیل را فارسی بنویسد.
